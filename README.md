# lol-2026-pickem
# 🏆 LoL Worlds 2026 Swiss Stage Simulator & Pick'em Tool

An interactive web app that lets you simulate and predict the League of Legends Worlds 2026 Swiss Stage matchups.

一個專為英雄聯盟 2026 世界賽瑞士輪打造的互動模擬預測網頁工具。

---

## 🌟 Key Features / 核心特色

- **Real Matchups / 真實官方對戰組合**  
  Features the official 16 qualified teams and locked Round 1 matches.  
  內建官方抽籤出爐的 16 支參賽戰隊，並完整鎖定第一輪官方對決。

- **Authentic Swiss Format / 嚴謹瑞士輪機制**  
  Dynamically matches teams based on real-time win-loss records without rematches.  
  依據即時勝負戰績自動動態撮合同分隊伍，並嚴格遵循「歷史對手不重複交戰」原則。

- **Hextech Client UI / 海克斯黑金風格**  
  Immersive dark-mode design inspired by the official LoL game client.  
  完美復刻 LoL 遊戲客戶端極具沉浸感的暗黑奢華視覺體驗。

- **Export Summary Card / 一鍵匯出戰報圖卡**  
  Generate and download a high-res summary card (3-0, 3-1, 3-2 & eliminated teams) with one click!  
  一鍵將預測結果（3-0、3-1、3-2 晉級隊伍與淘汰名單）渲染並下載為高畫質圖片！
